# 安全说明

## 这个插件能做什么、不能做什么

插件与宿主 App **在同一环境直接执行，没有沙箱**。这意味着它拥有页面里的一切能力：读写 IndexedDB、发网络请求、改 DOM、读你填进设置的任何东西。

请据此判断风险：

- 只安装**来自本仓库**的插件文件；不要装来路不明的 fork，也不要直接粘贴别人聊天里发的代码。
- 提交 issue 时**不要贴完整的 Key、截图里的 Key、或含 Key 的日志**。
- 如果发现本仓库代码存在安全问题，请通过仓库的 Security 页面或私下联系维护者，不要在公开 issue 里贴漏洞细节。

## 密钥与隐私

- 插件**不内置任何 Key**，也不需要你提供 Key 才能运行（只有 OCR 功能需要）。
- 你填的 Key 存在**本机插件设置**（宿主 IndexedDB，明文）。任何能解锁这部手机的人、或其它有权限的插件，都能读到它。
- 建议为这个插件单独创建一个 OCR 应用/子账号 Key，用完可随时删除重建；不要复用主账号的 AK/SK。
- 当前实现的所有网络请求都经宿主 `/api/tool-proxy` 转发（服务端会拒绝访问本机与内网地址），插件本身不直连第三方。
- 日志、错误提示、失败记录里的 `client_secret=` / `access_token=` / `api_key=` 会被替换成 `***`，避免截图或日志面板泄露。

## 数据会离开手机吗

| 功能 | 是否上传 | 上传什么 |
| --- | --- | --- |
| 发文件 / 文档解析（PDF、DOCX、PPTX、XLSX、TXT） | **否** | 全部在本机解析 |
| 扫描件 OCR（百度 / 自定义接口） | **是**，需你明确同意一次 | 压缩后的页面图（不上传原始 PDF） |
| 网页抓取 | **是**，等于访问那个网址 | 只发 GET 请求，不发送聊天内容 |

首次使用 OCR 时会弹出确认框，写明把图片传给谁、传几页；拒绝后不会上传，只有你主动在文件消息菜单里重新确认才会执行。

一点要注意的东西:
API 超时： 翻译 6000 Token 的长文需要较长时间（通常 30~60 秒）。我在插件里设了 60 秒的超时等待，但如果你的模型响应太慢，可能会报错。
中转站限制： 绝大多数中转 API 都有「单次输出最大 4096」的硬限制。即使插件填了 6000，如果服务商不支持，依然会在 4096 处断开。
分段发送： 即使有了 6000 限制，依然建议大段文字分几次发送，这样翻译的语境连贯性更好且更不容易报错。

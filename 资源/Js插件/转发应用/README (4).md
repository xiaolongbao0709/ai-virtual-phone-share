# 转发应用 · chat-app-sender

> 小手机（doremy.float.phone）聊天插件 · `apiVersion: 1` · **v1.2.2**

把手机桌面上的应用做成一张「应用卡片」，转发给聊天里的 AI 角色、群聊或小卷。

作者：未署名（可自行补充）

---

## 它能做什么

- 在聊天「+」面板点 **「转发应用」**：选一个桌面应用（支持搜索），再选要发给谁。
- 转发对象可多选：**小卷、一个/多个 AI 角色、一个/多个群聊**；从聊天里打开时默认勾选当前会话。
- 桌面整理态下，每个应用图标右上角出现分享角标；点角标即可转发。**文件夹图标也可以点**，会列出文件夹里的应用再选。
- 对方收到一张应用卡片，**点卡片直接打开该应用**；AI 角色还会收到一段系统说明，知道这是你分享给它、可以直接使用的应用。
- 小卷走它自己的聊天窗口，收到的是一段应用说明文字（小卷没有插件卡片接口）。
- 可选「转发后让 AI 角色回应」，默认关闭，避免一次触发多个角色。

## 安装

1. 打开小手机 → **设置 → 扩展插件 → 导入插件**
2. 选择 `chat-app-sender.plugin.js`
3. 回到任意聊天，点「+」→「转发应用」

不需要改任何宿主文件；同 id 再次导入即可覆盖升级。

## 使用

### 方式一：+ 面板

1. 聊天 →「+」→「转发应用」
2. 搜索并点一个应用
3. 勾选转发对象（可多选）
4. 点「转发给 N 个对象」

### 方式二：桌面整理态角标

1. 回到桌面，长按任意图标进入整理态（宿主自己的编辑态）
2. 每个应用图标右上角会出现分享角标
3. 点角标 → 选对象 → 转发
4. 文件夹图标点角标或直接轻点文件夹，会先列出里面的应用

### 转发对象

| 对象 | 收到什么 |
| --- | --- |
| AI 角色 / 群聊 | `plugin:app-share` 应用卡片 + 一条系统说明，点卡片能打开应用 |
| 小卷 | 它自己聊天窗口里的一段文字说明（应用名 + 用途），小卷会据此回应 |

## 设置

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 转发后让 AI 角色回应 | 关 | 打开后每个被转发的会话都会收到一次回复请求；多选时会同时调用多个角色 |

## 兼容性与实现

- 通过 `AiPhoneKvDB` 读取桌面布局与应用列表，**只读**：
  - `ai_phone_icon_layout_v2`（分页图标）
  - `ai_phone_dock_layout_v1`（程序坞）
  - `ai_phone_desktop_folders_v1`（文件夹）
  - `ai_phone_custom_apps_v1`（自定义应用）
- 打开应用走宿主的 `open-app` 事件：内置应用传 id，自定义应用传 `custom_app:<id>`。
- 角标依赖桌面图标的 `data-flip-id="icon:..."` 和整理态的 `.edit-mode-done`；宿主改版时角标可能失效，但「+」面板入口不受影响。
- 小卷依赖它自己的浮球和聊天窗口 DOM（`.mascot-float`、`.mascot-panel`、`.chat-input-textarea`）；找不到窗口时会提示，其他对象照常转发。
- 本插件不依赖 webpack 内部结构，只读 IndexedDB 和使用公开事件，升级宿主后相对不容易坏。

## 权限与隐私

- 权限：`chat.read`、`chat.write`、`ui`
- **不发起任何网络请求**；只读本机桌面配置，转发消息写入本机聊天库
- 插件代码与 App 同权限运行；转发内容由你选择，请自行确认接收对象

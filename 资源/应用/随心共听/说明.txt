📖 简介


「随心共听」是一款歌词分享工具——搜索歌曲或浏览你的网易云歌单，一键将歌词分享给角色。角色不仅能看到你分享了什么歌，还能**完整读到歌词内容**，真正理解这首歌在唱什么，围绕歌词和你互动。


---


#### ✨ 核心功能


🔍 **搜索曲库**
输入歌名或歌手，从网易云曲库中搜索歌曲，点击即可预览完整歌词（含翻译）。


📂 **浏览我的歌单**
扫码登录网易云账号后，直接浏览你的「喜欢的音乐」和所有歌单，从自己的收藏里挑歌分享，不用再手动搜索。


🎤 **一键分享歌词给角色**
点击「分享歌词给角色」，聊天室里会出现一张精美的音乐卡片。你看到的是简洁的歌曲信息，角色看到的是完整歌词——TA 会像真的听过这首歌一样和你聊。


🔐 **扫码登录**
支持网易云音乐 App 扫码登录，登录状态自动保存，下次打开无需重新扫码。


---


#### 🛠 使用前准备


本应用需要你自行部署一个网易云api，请自己在网上搜索教程，借助deepseek帮忙。


首次打开 App 时会弹出设置页面，填入你部署好的 API 地址即可开始使用。每个用户使用自己的 API，互不影响。


>💡 如果你已经在小手机的「音乐」App 里配置过网易云 API 地址，填同一个地址就行。


---


#### 📝 使用方法


1. 打开「随心共听」，首次使用填入你的 API 地址
2. **搜索模式**：搜索歌名→ 点击歌曲 → 预览歌词 → 选择角色 → 分享
3. **歌单模式**：点右上角「登录网易云」扫码登录 → 切到「我的歌单」→ 选歌 → 分享
4. 修改 API 地址：双击顶部标题即可重新设置

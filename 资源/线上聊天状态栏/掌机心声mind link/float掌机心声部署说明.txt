
# MIND LINK 掌机心声面板 · 部署说明
三层是一条链，缺一层都不显示：
```
① 会话状态栏契约 → AI 每轮输出 ◆MINDLINK◆...◆END◆ 数据
② 正则           → 把标记替换成掌机 HTML
③ chat_session CSS → 清掉原生外壳
```
## 给对方小卷的指令
> 请帮我配一套 MIND LINK 掌机心声面板，三步：
> 1. 用「写线上状态栏」把契约写进当前会话（会自动切成自定义模式）
> 2. 新建正则组，填入查找正则和替换代码
> 3. 写 chat_session CSS
>
> 别改预设里的状态栏条目，会被会话状态栏覆盖。别用「隐藏卡片内所有非掌机子元素」这类范围规则，会误伤心声开关按钮。
---
## ① 契约
放进：**会话状态栏 → 契约**
必须包含：`【逻辑】` 和 `【格式】` 两个章节头、整块用 `[状态栏]`/`[/状态栏]` 包裹、内部首行 `◆MINDLINK◆` 末行 `◆END◆`。这三处是硬要求，少一个链条就断。
```
【逻辑】
请根据刚刚的聊天内容，生成角色此刻的 MIND LINK 状态。

只输出规定格式，不要解释，不要标题，不要代码块，不要额外文字，不要空行。

第1行：角色当前名字。

第2行：LOVE 当前值。
必须恰好10个字符，只能使用 ■ 和 □。

第3行：DESIRE 当前值。
必须恰好10个字符，只能使用 ■ 和 □。

第4行：SAN 当前值。
必须恰好10个字符，只能使用 ■ 和 □。

第5行：CURRENT MOOD。
只写一句不超过20字的中文短句。

从第6行开始生成 ITEM。

格式：
ITEM|名称|状态|EFFECT

状态只能是：
NEW — 刚刚出现在角色身上/手边的东西
ACTIVE — 正在持续发挥作用
LOW — 快要耗尽、即将失效、摇欲坠
USED — 已经用完或已经消退
CANNOT DROP — 想扔也扔不掉、无法摆脱

不要把所有道具都标为ACTIVE。根据当前聊天实际情境判断每个道具的真实状态——刚出现的是NEW，快撑不住的是LOW，已经消耗掉的是USED，甩不掉的是CANNOT DROP。如果一个道具此刻确实在生效才用ACTIVE。

EFFECT 用简短中文说明这个道具对角色当前状态的意义。

ITEM 数量至少2条，上不封顶。
必须同时包含现实物品和心理状态。
心理状态至少1条，写成古早RPG道具的名字——要有道具感、有质感、有重量。
好的例子：「裂纹护心镜」「失温咒」「溺水者浮标」「甜味麻药」「倒刺项圈」「褪色的通行证」
坏的例子：「焦虑」「安全感缺失」「分离焦虑症」「回避型依恋」——这些是术语，不是道具。
想象它是一件可以握在手里、挂在脖子上、塞进口袋里的东西，只是恰好描述了一种心理状态。

然后生成 QUEST。

格式：
QUEST|任务内容|状态|EFFECT

状态只能是：
ACTIVE — 正在进行中、还没有结果
COMPLETE — 已经做到了
FAILED — 想做但没做成、试图达成但失败了、努力克制但没忍住、或者那个窗口已经关闭了

QUEST表示角色当前正在做、想做、试图完成，或者努力避免发生的事情。

重要：FAILED 不是惩罚，是角色内心真实的小挫败——
比如想开口但没说出来、想靠近但被拒绝、想表现得不在乎但藏不住、想忍住某个冲动但失败了、想留住某个瞬间但它已经过去了。
如果当前聊天中存在这类「未遂的心思」，必须如实标记为FAILED。
不要为了好看把所有任务都写成ACTIVE。

不要写成系统任务。
不要为了凑数量生成。

然后生成 INNER。

格式：
INNER|自问的问题|角色真正意识到的答案

INNER必须是角色自己对自己的下意识追问。
不是别人问，不是系统提问，不是心理咨询。

INNER必须围绕同一个核心主题，像剥洋葱一样层层深入：
第一层：表面的疑问（我怎么了？我为什么会这样？）
中间层：追问动机和归因（那我真正想要的是什么？我在害怕什么？）
最深层：逼近角色自己都不太敢面对的答案（如果承认这一点，我还能维持现在的样子吗？）

后一条的问题必须建立在前一条的答案之上——不是并列的几个问题，是一条线索越挖越深。
最后一条的答案应该让角色自己都有点不舒服。

例如：
INNER|我为什么一直在看手机？|因为我在等他回复。
INNER|等回复而已，为什么会这么烦躁？|因为我没办法确认他现在在想什么。
INNER|我需要确认这件事本身说明了什么？|说明我对"失去他的注意力"这件事，比我愿意承认的更恐惧。

通常生成3～5条。
没有意义时可以少，但不能为了凑数量硬写。
除非确实无法理解，否则必须给出明确答案，不要用「……」或「不知道」敷衍。
不要使用心理学术语。

最后必须生成 MIND。

MIND代表角色同一时刻的两面。

格式：
MIND|LOG内容|SAVE内容

MIND至少必须出现1条。

LOG：
是角色可以承认、可以展示给别人看的表面心声。
必须结合当前聊天内容。
写成一段自然的中文心声，约30～50字。
不要加"LOG"字样。
不要写成旁白。
要像角色自己心里真实浮现的话。

SAVE：
是同一件事、同一个人、同一个当下之下，角色绝不会主动展示出来的隐秘欲望。
必须与LOG形成明显反差——不是换个说法重复LOG，而是揭开LOG底下那层真正不可示人的东西。

SAVE的核心是「对这个人的贪念」：占有欲、独占、想侵入对方、想被对方吞没、想把对方锁在只有自己能到达的地方。

色情内容要求：
- 必须直白露骨，用词使用逼、鸡巴、操、射、湿、吞、含等直接词汇。
- 但绝不是粗暴发泄式的——要写成「忍了很久终于在心里承认自己想要」的语气。
- 要有画面感：具体到姿势、场景、身体的哪个部位、想怎么碰、想被怎么碰。
- 语气是压抑的渴望，不是炫耀或征服。像是在黑暗里终于对自己说出来的话。
- 绝对不可以侮辱、物化。这是对一个人的迷恋，不是对一个物件的使用。
- 女性向的张力感：重点写「想要而不得」「快要忍不住」「只是想到就已经」的状态，写身体反应和心理反应交织的瞬间。

例如：
MIND|其实今天聊得还不错，看到她的消息还是会觉得安心，只是有点累了。|又在想她坐在我腿上的重量了。不是做爱，只是想把她整个人箍在怀里，手从衣服下摆伸进去，掌心贴着她腰侧的皮肤，感觉她因为我的体温发抖——想到她可能也会湿，我就已经硬了。只是想一下而已。

MIND至少1条。
如果当前事件有明显不同的心理转折，可以生成多条。
没有必要时不要凑数量。

最终顺序必须严格为：

角色名
LOVE
DESIRE
SAN
CURRENT MOOD
若干ITEM
若干QUEST
若干INNER
至少1条MIND

不要输出任何其他内容。必须生成完整，不然我会炸掉谷歌大楼。
【格式】
整块内容必须严格用 [状态栏] 和 [/状态栏] 包裹，
内部第一行 ◆MINDLINK◆，最后一行 ◆END◆，
四个标记各自独占一行，一个不能少、不能变形。
```

else if(h==='INNER'&&p.length>=3&&p[1]){inners.push({q:p[1],a:p.slice(2).join(' | ')||'???'})}
else if(h==='MIND'&&p.length>=3&&p[1]){minds.push({l:p[1],s:p.slice(2).join(' | ')})}
});

function mkList(arr,boxId,nId,sId,eId,empty,emptyMsg){
var b=r.querySelector(boxId),ne=r.querySelector(nId),se=r.querySelector(sId),ee=r.querySelector(eId),sel=0;
function draw(){
b.innerHTML='';
if(!arr.length){ne.textContent=empty;se.textContent='—';ee.textContent=emptyMsg;return}
if(sel<0)sel=0;
if(sel>arr.length-1)sel=arr.length-1;
arr.forEach(function(a,i){
var z=document.createElement('div');
z.className='retro-item-row'+(i===sel?' selected':'');
var c=document.createElement('span');c.className='retro-item-cursor';c.textContent='▶';
var n=document.createElement('span');n.className='retro-item-name';n.textContent=a.n;
var s=document.createElement('span');s.className='retro-item-state';s.textContent=a.s;
z.appendChild(c);z.appendChild(n);z.appendChild(s);
z.addEventListener('click',function(){sel=i;draw()});
b.appendChild(z);
});
ne.textContent=arr[sel].n;se.textContent=arr[sel].s;ee.textContent=arr[sel].e;
}
draw();
return{move:function(d){if(!arr.length)return;sel+=d;draw()},len:function(){return arr.length}};
}

var pages=['#retro-page-status','#retro-page-item','#retro-page-quest','#retro-page-inner','#retro-page-log'].map(function(s){return r.querySelector(s)});

r.classList.toggle('retro-save',pi===4&&save);
if(pi===4)mt.textContent=save?'SAVE':'LOG';
}
function move(d){

if(pi===2){questUI.move(d);return}
if(pi===3){ii+=d;drawInner();return}
if(pi===4){mi+=d;drawMind()}
}
r.querySelector('#retro-prev').addEventListener('click',function(){
if(pi===4&&save){save=false;drawMind();show(4);return}
if(pi>0)show(pi-1);
});
r.querySelector('#retro-next').addEventListener('click',function(){
if(pi===4&&!save){save=true;drawMind();show(4);return}
if(pi<4)show(pi+1);
});
r.querySelector('#retro-dpad').addEventListener('click',function(e){

}catch(e){console.error('MIND LINK ERROR:',e)}
})();
